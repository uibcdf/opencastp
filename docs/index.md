# OpenCASTp

OpenCASTp is an incubating local CASTp reconstruction. The Python reference
accepts explicit atomic spheres; molecular preparation is caller-owned.
Rust/GPU and complete modern-server equivalence are not current claims.

Detected regions expose unit-bearing solvent-accessible and molecular-surface
areas and volumes. Polyhedral fields remain separate. Analytical mouth
areas/perimeters and general server equivalence are still being validated.
Complete equivalence is the sole current scientific priority under
[issue #6](https://github.com/uibcdf/opencastp/issues/6); all other improvements
are deferred.
